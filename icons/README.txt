=== Иконки Astra — Древо Щит ===

Для работы в браузере нужны PNG-иконки трёх размеров:
  - icon16.png  (16?16)
  - icon48.png  (48?48)
  - icon128.png (128?128)

Как получить:
1. Откройте logo.svg в Inkscape, Figma или любом редакторе.
2. Экспортируйте в PNG в трёх размерах выше.
3. Положите файлы в эту папку.

Или используйте онлайн-конвертер:
  - https://cloudconvert.com/svg-to-png
  - https://convertio.co/svg-png/

Для dev-режима иконки не обязательны — Chrome покажет иконку по умолчанию.
Для загрузки в Chrome Web Store — обязательны.
